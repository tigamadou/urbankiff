# Urbankiff Next.js App

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🔧 Code Quality

This project uses ESLint and Prettier for code quality and formatting.

### Available Commands

```bash
# Basic linting
npm run lint

# Strict linting (no warnings allowed)
npm run lint:strict

# Auto-fix linting issues
npm run lint:fix

# Check TypeScript types
npm run type-check

# Auto-format code
npm run format

# Check code formatting
npm run format:check
```

### GitHub Actions

- **Automatic checks** run on every pull request
- **Auto-fix** capabilities for common issues
- **Quality gates** prevent merging with issues
- **PR comments** provide feedback on code quality
